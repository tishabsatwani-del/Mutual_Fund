This repository holds exactly two published things and nothing else.

## Two Doors, One Storm

A mobile-first behavioural investing simulator that accompanies the book.
Two people invest the same money in the same market; the only variable is
what holds their hand when it falls. It never tells the reader which door
to take — it puts two numbers side by side and lets them do the sum.

**Live:** `https://tishabsatwani-del.github.io/Mutual_Fund/`

The page is a gate. The simulator is stored inside it encrypted and opens
with a reader's access code printed in the book. The check runs entirely in
the browser; nothing typed ever leaves the device.

## The Portfolio Reality Check

A free, open companion tool for working out where a real portfolio actually
stands — XIRR, holdings and returns, from a statement the reader already has.
No access code. Nothing uploaded: every calculation happens on the device.

**Live:** `https://tishabsatwani-del.github.io/Mutual_Fund/tool/`

## What is deliberately not here

No readable simulator source, no manuscript text, no build tooling, no
engine tests, and no history containing any of them. Those live in a
separate private repository and are never published.
